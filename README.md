# game-assignmant
## 팀원 이름
#### 박준현, 전석호

## 역할 분담
#### 드라이버: 박준현 
#### 네비게이터: 전석호

## 실행방법
#### 1. card game.slnx를 실행한다.
#### 2. 행과 열을 입력하여 카드를 확인한다.
#### 3. 다시 한번 행과 열을 입력하여 동일한 카드일시 카드가 뒤집힌다.
#### 4. 해당 과정을 반복하여 모든 숫자를 뒤집는다.
#### <mark>주의사항: 숫자 입력시 반드시 행과 열을 띄어써야한다(ex:1 3)</mark> 
#### <mark>같은 카드를 입력하거나 이미 뒤집은 카드를 선택할 수 없다</mark>
